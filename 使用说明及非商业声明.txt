使用许可：本项目中权利人拥有的原创内容仅供个人学习、研究和非商业用途。未经权利人事先书面许可，不得用于商业项目、收费服务、出售或其他商业用途。第三方组件及素材仍适用各自的许可。

AI API 配置：
1. 如果目录中没有 config.json，请先复制 config.example.json 并重命名为 config.json；然后用记事本打开 config.json。
2. 在 api_key 的引号内填入您自己的 API Key。
3. 默认使用阿里云百炼兼容接口；可在 api_url 和 models 中修改兼容的聊天接口地址和模型名称。
4. 保存文件后运行 GEO全流程自动化引擎.exe。程序运行时读取配置。
5. API Key 以明文保存在本地配置文件中，请勿将填写后的 config.json 分享或上传。若不填写，程序仍可执行搜索采样，但不会执行大模型问答采样。API 调用可能产生服务商费用。
